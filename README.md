# 豆包无水印图片选择下载脚本

一个用于豆包图片页面的油猴脚本。

## 功能

- 自动识别豆包返回的无水印原图地址
- 按住 `Alt` 点击图片进行选中
- 只下载你选中的图片

## 文件

- `remove.user.js`：脚本主文件

## 安装

1. 安装 Tampermonkey
2. 导入 [remove.user.js](./remove.user.js)
3. 打开豆包图片页面使用

## 使用方法

1. 等待豆包图片加载完成
2. 按住 `Alt` 点击要下载的图片
3. 点击右下角 `下载选中`

## 适用范围

- 适用于 `https://www.doubao.com/*`
